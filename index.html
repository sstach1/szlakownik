Logowanie

Zaloguj się tokenem z GitHuba. Zmiany zapisują się w Twoim repozytorium, a sklep aktualizuje się po około minucie.

Skąd wziąć token?
  1. Otwórz github.com/settings/personal-access-tokens/new.
  2. Nazwa: Szlakownik panel. Ważność: np. 90 dni.
  3. Repository access: Only select repositories → wybierz repozytorium sklepu.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Kliknij Generate token, skopiuj go i wklej powyżej.
